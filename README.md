# 🪙 3D コイントスローグライク - Three.js版

Three.jsを使用した3D物理演算コイントスローグライクブラウザゲーム。スキルコインを選択し、3Dでトスしたコインの結果でバトルを進める。

## 特徴

### 🎮 3D物理演算システム
- **リアルなコイン物理** - 重力、速度減衰、回転減衰を実装
- **反発と衝突** - 床や壁への衝突判定と反発処理
- **回転検出** - コインの最終的な向きで表/裏を判定
- **動的なカメラ** - 3D空間からの俯瞰視点

### 🛠️ 技術スタック
- **Three.js** - 3Dシーン、レンダリング、ライティング
- **Canvas** - WebGLレンダリング
- **カスタム物理演算** - 軽量で高速な物理シミュレーション
- **Vanilla JavaScript** - フレームワーク不要

### 🎯 ゲームシステム
- **スキル選択** - 毎ラウンド3つのランダムスキルから選択
- **コイントス** - 3D物理演算でコインを実際にトス
- **表/裏判定** - 表が出たらスキル発動、裏が出たら失敗
- **敵バトル** - ラウンド進行につれて敵が強化
- **進行報酬** - ゴールド獲得と難易度スケーリング

## スキルシステム（30種類以上）

### 攻撃スキル ⚔️
- **斬撃** - 25ダメージ
- **火炎爆破** - 40ダメージ
- **雷撃** - 30-45ダメージ（追加チャンス）
- **貫通攻撃** - 20ダメージ（防御無視）

### 防御スキル 🛡️
- **シールド** - 50%ダメージ軽減
- **回避** - 次攻撃を確定回避
- **スキンハード** - 30%ダメージ軽減

### 回復スキル 💚
- **ヒール** - 30HP回復
- **大ヒール** - 50HP回復
- **フルリカバリ** - 全HP回復
- **再生** - 毎ラウンド2HP自動回復

### バフ/デバフ
- **パワーアップ** - 3ラウンド攻撃力1.5倍
- **ポイズン** - 敵に毒（3ラウンド）
- **弱体化** - 敵攻撃50%低下
- **その他20種類以上**

## ゲーム進行

```
ゲーム開始
    ↓
スキル選択フェーズ
    ↓
コイントスフェーズ（3D物理演算）
    ↓
結果表示フェーズ（表/裏判定）
    ↓
スキル発動 or 失敗
    ↓
敵の反撃（ラウンド+2ダメージ）
    ↓
HP > 0 ? → 次のラウンドへ
HP ≤ 0 ? → ゲームオーバー
```

## 難易度調整

- **初期HP**: 100
- **敵基本攻撃力**: 15 + (ラウンド × 2)
- **5ラウンド毎**: 最大HP +50、現在HP +50回復
- **無制限進行**: ラウンド数に制限なし

## 起動方法

### 方法1: ローカルサーバー起動
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (http-server)
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセス

### 方法2: 直接ファイルを開く
ブラウザで `index.html` をドラッグ&ドロップするか、右クリック → 「プログラムから開く」

## 物理演算の実装詳細

### 重力とダンピング
```javascript
velocity.y += gravity * deltaTime;
velocity *= damping; // 速度減衰
angularVelocity *= angularDamping; // 回転減衰
```

### 衝突と反発
```javascript
if (position.y <= 0.3) {
  position.y = 0.3;
  velocity.y *= -bounceElasticity;
}
```

### 着地判定
```javascript
if (velocity.magnitude < threshold && position.y < groundLevel) {
  coin.finishFlip();
  // 回転値から表/裏を判定
}
```
