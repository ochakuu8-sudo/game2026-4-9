# 🪙 コイントスローグライク - スキルゲーム

スマートフォン対応のコイントスローグライクブラウザゲーム。スキルコインを選択し、コイントスで表が出たらスキルが発動します！

## ゲームの特徴

### 🎮 コアメカニクス
- **スキル選択**: 毎ラウンド、3つのランダムなスキルから1つを選択
- **コイントス**: 選択したスキルを発動するためにコインをトス
- **表が出ると発動**: 表 = スキル発動、裏 = スキル失敗

### 💪 多様なスキルシステム
30種類以上のスキルが用意されています：

#### 攻撃スキル
- 斬撃 ⚔️ - 基本的なダメージ
- 火炎爆破 🔥 - 強力な火炎攻撃
- 雷撃 ⚡ - 追加ダメージチャンス
- 貫通攻撃 🏹 - 防御を無視

#### 防御スキル
- シールド 🛡️ - ダメージを50%軽減
- 回避 💨 - 次の攻撃を確定回避
- スキンハード 🪨 - 体を硬くしてダメージ軽減

#### 回復スキル
- ヒール 💚 - 30HP回復
- 大ヒール 💖 - 50HP回復
- フルリカバリ ✨ - 全HP回復
- 再生 🌿 - 毎ラウンド自動回復

#### バフスキル
- パワーアップ 💪 - 3ラウンド攻撃力1.5倍
- スピードアップ ⚡ - 次ラウンドスキル2つ選択
- 集中 🎯 - 次スキル発動率100%

#### デバフスキル
- ポイズン ☠️ - 敵に毒(3ラウンド)
- 弱体化 👻 - 敵の攻撃力50%低下
- ブラインド 🌫️ - 敵の命中率低下

#### サポートスキル
- ゴールドハンター 💰 - 次ラウンド報酬金2倍
- スキルサーチ 🔍 - レアスキル出現
- ライフリンク 🔗 - ダメージの20%をHP回復

#### 特殊スキル
- ダブルダウン 🎲 - 追加ターン
- ギャンブル 🎰 - 50～80ダメージ（ハイリスク）
- 運命の一手 🌠 - 100ダメージ＋全HP回復
- コンボ 🔄 - 前回スキルも発動

#### 変換スキル
- サクリファイス 🔺 - HP消費して敵に攻撃
- ソウルシャッター 💎 - HP消費で高ダメージ

### 🌟 レアスキル
スキルサーチで追加出現：
- オムニスラッシュ 🌪️ - 120ダメージ
- 時間停止 ⏸️ - 敵の2ターン無効化
- ゴッドモード 👑 - 5ラウンド無敵

## ゲーム進行

1. **ゲーム開始** - タイトル画面からゲーム開始
2. **スキル選択** - 3つのスキルから1つを選択
3. **コイントス** - コインをトスして表を祈る
4. **結果判定** - スキルが発動するか、敵の反撃ダメージを計算
5. **敵の攻撃** - プレイヤーがダメージを受ける
6. **ラウンド進行** - ゴールドを獲得してラウンド進行
7. **ゲームオーバー** - HPが0以下になったらゲーム終了

## 難易度調整

- ラウンドが進むたびに敵の攻撃がやや強化される
- 5ラウンドごとに最大HPが増加（50ずつ）
- スキルの戦略的な組み合わせがカギ

## 操作方法

### PC/タブレット
- マウスクリックでスキルを選択
- ボタンタップでコインをトス

### スマートフォン
- タッチでスキルを選択
- タップでコインをトス
- 完全なレスポンシブ対応

## プレイのコツ

1. **バフの活用** - 攻撃力アップなどのバフを積極的に利用
2. **回復の確保** - 回復スキルで重要な局面を凌ぐ
3. **敵のデバフ** - 毒や弱体化で敵を制御
4. **金の効率** - ゴールドハンターで報酬を増加
5. **連携プレイ** - スキルの効果を組み合わせる

## ゲーム開始

ブラウザでこのリポジトリのファイルを開くか、ローカルサーバーで実行してください：

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (http-server)
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。
